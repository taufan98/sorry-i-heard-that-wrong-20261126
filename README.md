A single original one-line apology a smart speaker gives its owner after mishearing them, for make.fun's "Sorry, I Heard That Wrong" bounty. The program writes the line to `/output/entry.txt` (1–140 chars, one line) for the house judge to compare against other entries.

## Run it

```sh
python3 main.py
```

## The entry

> Sorry, I heard 'call Mom' as 'call the mob.' They're on their way, they sound lovely, and they've already forgiven you.
